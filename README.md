# Оценка качества вина — Streamlit

Приложение предсказывает, получит ли вино оценку от 7 баллов. Используется `StandardScaler` и `LogisticRegression`. Порог **0.2689** выбрал по F1 на валидации.

## Запуск

Версия Python для запуска: **3.13**. Зависимости зафиксированы в `requirements.txt`.

```bash
cd wine_app
python -m pip install -r requirements.txt
streamlit run app.py
```

Папка должна содержать `app.py`, `model.joblib`, `config.json`, `test.csv` и `requirements.txt`. Переобучать модель для приложения не требуется.

## Возможности

- **Одно вино:** ручной ввод 12 признаков; числовые диапазоны и медианы взяты из `test.csv`, `is_red` — переключатель.
- **Модельные метрики:** матрица ошибок, precision, recall, F1 и ROC/PR-кривые с текущей рабочей точкой.
- **Пакетное предсказание:** загрузка CSV и скачивание таблицы с вероятностями и решениями. Если обязательных столбцов нет, появляется сообщение об ошибке.
- **Коэффициенты:** вклад признаков после стандартизации.

Порог из сайдбара применяется ко всем вкладкам. Изменение порога не запускает повторное обучение.

## Кэширование

`st.cache_resource` использую для модели, чтобы не загружать её заново. `st.cache_data` — для таблицы и готовых вероятностей. В `test_proba` аргумент `_model` не участвует в ключе кэша. Без декоратора `joblib.load` будет читать модель с диска при каждом изменении порога, поэтому приложение станет медленнее.
